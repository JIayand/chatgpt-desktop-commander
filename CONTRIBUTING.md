# Contributing

1. Open an issue to describe a bug or proposed change before large refactors.
2. Keep changes focused and include regression tests where practical.
3. Run `npm test` before submitting a pull request.
4. Do not commit `config/config.json`, `config/config.local.json`, logs, usage data, tunnel credentials, private keys, or personal absolute paths.
5. Document platform-specific behavior and security implications.

By submitting a contribution, you agree that it may be distributed under this project's MIT License.
